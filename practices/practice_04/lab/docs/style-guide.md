# Style guide (коротко)

1. Проверяй поведение через публичные функции `subscribe` / `list_subscribers`.
2. Не добавляй внешние зависимости — только stdlib.
3. Ошибки входа — через исключения с понятным текстом.
4. Не ослабляй тесты ради зелёного результата.
5. Перед правкой кода прочитай этот файл и `docs/requirements.md`.
