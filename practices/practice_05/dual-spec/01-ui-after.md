# Команда 1 — спека UI (ПОСЛЕ контракта)

## Экраны / команды

Текстовый CLI без TUI:

- `python cli.py` / `help` — список команд
- `subscribe <name>` — подписка, одна строка успеха
- `list` — имена по одному на строку (или `(empty)`)
- `unsubscribe <name>` — одна строка успеха

## Состояния

- Успех: stdout, exit 0
- Ошибка домена: stderr с текстом (`empty name` / `unknown name`), exit 1
- Неверная команда / usage: stderr, exit 2

## Ошибки (как видит пользователь)

- Пустое имя → `empty name`
- Нет такого подписчика → `unknown name`
- Отдельного меню выбора нет — имя передаётся аргументом

## Вне скоупа

Цвета, стрелки, интерактивный prompt-цикл.
