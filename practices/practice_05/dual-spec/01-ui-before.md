# Команда 1 — спека UI (черновик ДО согласования)

Проект: Notify Mini. Экран = терминал, без веб-форм.

## Экраны / команды

1. Стартовый экран: список доступных действий.
2. Подписка: пользователь вводит имя в одной строке.
3. Список: показать всех подписчиков.
4. Отписка: выбрать имя из меню со стрелками (как в TUI).
5. После каждой команды — цветной статус (зелёный/красный).

## Состояния

- `idle` — ждём команду
- `awaiting_name` — ждём ввод имени
- `menu_select` — выбираем кого удалить стрелками
- `error` — мигающее сообщение 3 секунды

## Ошибки (как видит пользователь)

- Пустое имя → «Имя не может быть пустым», остаёмся на том же экране
- Имя не найдено → «Такого подписчика нет», меню не закрываем
- Нет подписчиков при отписке → пустое меню с текстом «некого удалять»

## Заметки команды UI

Хотим «красиво»: стрелки + цвета. API пока не смотрели — предполагаем, что бэкенд отдаст список для меню и отдельный endpoint удаления.
