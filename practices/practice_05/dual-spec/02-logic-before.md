# Команда 2 — спека логики (черновик ДО согласования)

Проект: Notify Mini. In-memory set, stdlib only.

## Данные

- `subscribers: set[str]` — уже есть
- Новых сущностей не планируем

## API

```
unsubscribe(name: str) -> bool
```

- `True` если имя было и удалили
- `False` если имени не было
- Пустую строку считаем обычным «не найдено» → `False` (без исключения)

## Правила

1. Имя нормализуем через `.strip()` и `.lower()` (хотим case-insensitive).
2. Persistence не делаем.
3. CLI / UI вне скоупа этой спеки — только функции сервиса.
4. HTTP не добавляем.

## Ошибки

Исключения не бросаем: вызывающий код сам смотрит на `bool`.

## Заметки команды логики

Не хотим тащить curses/цветной TUI. Case-insensitive кажется удобным, но subscribe сейчас case-sensitive — надо решить на стыке.
