# Constitution (Spec Kit style) — Notify Mini

Урезанный constitution под учебный сервис, чтобы сравнить процесс со OpenSpec.

## Неизменяемые правила

1. Язык реализации: Python 3, только stdlib.
2. Source of truth поведения — markdown-спеки + тесты; код не должен молча расширять scope.
3. Library-first: доменная логика в `service.py`, CLI — тонкая оболочка.
4. Ошибки входа — через исключения с стабильным текстом.
5. Данные только в памяти процесса.
6. Перед кодом фиксируем spec → plan → tasks; после приёмки не оставляем «висящие» TBD в спеке.
