# Few-shot

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- Артефакт Практики 1: [`context.md`](../../practice_01/context.md)
- Что хотим улучшить: строка «Как устроен текущий процесс?» описывала TO BE (поведение помощника) вместо AS IS (ручной review)

## Примеры

### Хороший результат

```text
Как устроен текущий процесс?
Автор открывает PR → ревьюер вручную читает diff и пишет комментарии →
автор правит → approve/merge. AI-помощника в AS IS нет.
Источник: analysis.md, раздел AS IS.
```

### Плохой результат

```text
Как устроен текущий процесс?
Помощник получает diff и возвращает ≤3 риска с файлом и строкой.
Источник: README, «Задача помощника».
```

Плохой вариант смешивает целевое поведение продукта с текущим процессом.

## Запрос

Ниже два примера ответа на вопрос «Как устроен текущий процесс?» для таблицы AS IS в context.md.
Хороший отделяет ручной процесс от будущего помощника. Плохой подменяет AS IS описанием TO BE.
Перепиши строку таблицы в context.md в стиле хорошего примера. Не меняй Context Pack.

## Что получили

Предложена формулировка ручного AS IS с отсылкой к analysis.md; явно указано, что AI-помощника в AS IS нет.
