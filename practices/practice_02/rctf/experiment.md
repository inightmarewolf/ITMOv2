# R.C.T.F.

Файл ведёт OpenCode по вашим запросам. Агент записывает фактические результаты экспериментов и вносит изменения в связанные файлы. Свою оценку сообщайте ему в чате; вручную заполнять шаблон не нужно.

- **Role:** аналитик SDLC, разделяющий AS IS и TO BE
- **Context:** учебный кейс AI-помощника code review; AS IS уже описан в analysis.md; Context Pack — правила помощника
- **Task:** переименовать и перестроить разделы context.md так, чтобы AS IS и Context Pack (TO BE) нельзя было перепутать
- **Format:** заголовки markdown + таблица AS IS + явная пометка, что Context Pack относится к TO BE

## Полный запрос

Role: ты аналитик SDLC.
Context: в context.md таблица «Продукт и команда сейчас» и Context Pack смешаны: читатель думает, что помощник уже работает.
Task: (1) переименуй секцию AS IS с пометкой (AS IS); (2) озаглавь Context Pack как TO BE; (3) добавь одно предложение перед Context Pack, что это правила будущего помощника.
Format: только правки заголовков и одной вводной фразы; не удаляй факты Context Pack.

## Что получили

Секции стали: «Продукт и команда сейчас (AS IS)» и «Context Pack … (TO BE)» + явная оговорка перед Context Pack.

## Что изменили в исходном артефакте

- Файл и раздел: [`context.md`](../../practice_01/context.md) → заголовки AS IS / Context Pack
- Изменение: явная маркировка AS IS vs TO BE; вводная фраза к Context Pack
- Как проверили: по оглавлению файла нельзя спутать «сейчас» и «помощник»
- Что отклонили: дублировать весь BPMN/flowchart из analysis.md внутрь context.md
